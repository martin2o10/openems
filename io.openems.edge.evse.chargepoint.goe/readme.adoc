= EVSE Charge-Point go-e

Implementation for the go-e Gemini charging station series.

== Supported devices

- go-e Gemini
- go-e Gemini flex

== Communication

This component communicates via Modbus/TCP (go-e Modbus TCP API v2). The Modbus interface has to be enabled in the go-e App or via the HTTP API key `men`. Writes use function code 16 only, because function code 6 is not supported by go-e.

== Features

- Supports reading of meter values (voltage, current, power, energy)
- Supports setting charging current
- Supports enabling and disabling charging
- Supports switching between 1-phase and 3-phase charging
- Maximum charging current is limited by the hardware maximum of the charge point
