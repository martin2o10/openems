= EVSE Charge-Point ABL eM4

Implementation for the ABL eM4 charging station series in stand-alone operation.

== Supported devices

- ABL eM4 Single
- ABL eM4 Twin (one component per outlet)

Groups of eM4 Controller and Extender are not supported.

== Communication

This component communicates via Modbus/TCP according to ABL "Modbus TCP - Schnittstellenbeschreibung Wallbox eM4 Controller / Extender", R 01, 19.12.2023. The charge point identifies itself by its IP address; the Unit-ID is 255. Only function codes 3 and 16 are supported.

== Features

- Supports reading of meter values (voltage, current, power, energy)
- Supports setting the charging current in steps of 0.1 A; a current of 0 A stops charging
- Maximum charging current is limited by the maximum current of the installation (Idefault)
- Phase switching is not supported, because the Modbus interface does not provide it
